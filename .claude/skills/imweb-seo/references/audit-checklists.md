## B. 디자인모드 진단 — 읽기 전용 (INV-11)

> 아래는 **확인·기록만** 한다. 어떤 항목도 수정하지 않는다.

### B-1. 접근 전 확인
브라우저 로그인 상태 · 관리자 접속 상태 · 디자인모드 진입 가능 여부 · 화면 기록 권한 · 클릭/키보드 제어 가능 여부

접근 실패 시: `디자인모드 접근 실패` 기록 → 공개·API 진단은 계속 → 확인 필요 항목만 목록화 → 수정 보류

### B-2. 메뉴 SEO 확인 경로
디자인모드 접속 → 메뉴 관리 → 대상 메뉴 우측 `i` 아이콘 → 메뉴 설정 창 → 메뉴명 / 메뉴 주소 / 페이지 제목 / 페이지 설명 / 접속 권한 / 검색 노출 충돌 여부 확인 → 캡처 저장

**출력표**
`메뉴명 / URL / 현재 페이지 제목 / 키워드 후보와 일치 여부 / 현재 페이지 설명 / 수정 후보 / 접속권한 / 검색노출 문제 / 수정 위치 / 승인 필요 / 상태`

**주의**
- 메뉴명 변경과 페이지 제목 변경은 다르다. **메뉴명은 INV-11로 불가침.**
- URL 변경은 SEO 영향이 크다. **불가침.**
- 페이지 제목/설명은 SEO 필드이므로 승인 후 수정 가능.
- 사용자 키워드와 충돌하면 자동 교체하지 말고 질문.

### B-3. 본문 구조 확인 (보고 전용)
첫 화면 대표 문구 · H1 역할 문구 · H2 섹션 제목 · H3 세부 제목 · CTA 위치/문구/링크 · 이미지 위주 섹션 여부 · 텍스트 부족 여부 · 모바일 첫 화면 CTA 여부 · 모바일 문단 길이 · 섹션 순서 · 반복 섹션 · 숨김 섹션 · PC/모바일 표시 차이

**출력표**
`URL / 섹션 / 현재 문구 / 문제점 / SEO·AEO 개선안 / 모바일 개선안 / 적용 가능 여부(항상 "권장·미적용")`

### B-4. 이미지 ALT

**ALT 작성 가능 대상**
이미지 위젯 · 갤러리 위젯 · 텍스트 위젯 안 이미지 · 게시글 본문 이미지 · 상품 상세설명에 직접 삽입한 이미지 · HTML 위젯 코드 안에서 직접 수정 가능한 `img` 태그

**ALT 작성 제외 대상**
비주얼 섹션 · 섹션 배경 이미지 · 상품 대표 이미지 · 상품 썸네일 · 쇼핑 위젯 자동 상품 이미지

> ALT를 전체 이미지에 일괄 적용할 수 있다고 가정하지 않는다.

**출력표**
`URL / 이미지 위치 / 현재 ALT / 수정 ALT 후보 / 이미지 용도 / 주변 텍스트 / 수정 필요 / 승인 필요`

### B-5. 갤러리 위젯
갤러리 선택 → 설정 확인 → 이미지별 설명·ALT 상태 확인 → 없으면 후보 작성 → 캡처 저장 → 승인 전 수정 금지

**출력표**
`URL / 갤러리명 / 이미지 번호 / 현재 설명 / ALT 상태 / 수정 ALT 후보 / 승인 필요 / 상태`

### B-6. 코드 위젯
위치 · 소속 페이지 · 화면용 HTML인지 · 팝업인지 · CTA인지 · JSON-LD인지 · CSS/JS인지 · Header Code와 중복인지 · 로컬 원본 존재 · 공개 페이지 실제 반영 여부

**주의:** 원본이 보여도 바로 수정하지 않는다. 로컬 원본과 대조하고, 없으면 먼저 백업한다. 화면용 코드와 SEO용 Header Code를 섞지 않는다.

**출력표**
`URL / 코드 위젯 위치 / 코드 목적 / 로컬 원본 여부 / 공개 반영 여부 / 중복 가능성 / 수정 필요 / 승인 필요`

## C. GA4 / GTM / Google Tag 검수 순서

관리자 접속 → 환경설정 → 데이터 연결 → Google 애널리틱스 연결 여부 → `G-` 측정 ID 존재 → GTM 컨테이너 존재 → Google Tag 직접 삽입 여부 → Header Code GA4 중복 → Body/Footer GTM 중복 → 실시간 보고서 수집 여부 → (쇼핑몰) 전자상거래 추적 사용 여부 → API Secret 입력 여부 → 구매·장바구니·결제시작 이벤트 수집 여부 → 네이버페이 전환추적 옵션 필요 여부

**상태값**
GA4 직접 연결 확인 · GTM 관리 방식 확인 · Google Tag 직접 삽입 확인 · 중복 설치 의심 · 전자상거래 추적 확인 · 전자상거래 추적 미확인 · API Secret 확인 필요 · 실시간 수집 확인 · 실시간 수집 미확인 · 사용자 확인 필요

**출력표**
`항목 / 현재 상태 / 연결 방식 / 중복 여부 / 확인 근거 / 수정 필요 / 승인 필요`

**금지:** 같은 `G-` ID를 데이터 연결·Header Code·GTM에 동시 삽입. 중복 의심 시 삭제하지 말고 `중복 정리 필요`로 보고.
