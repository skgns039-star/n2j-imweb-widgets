## 2. 추정 금지 목록 (INV-13)

아래는 확인되지 않으면 **어떤 산출물에도 넣지 않는다.**

수치 · 후기 · 인증 · 가격 · 재고 · 할인 · 평점 · 순위 · 오프라인 매장 · 납품 실적 · 수상 이력 · 전문 자격 · 치료 효과 · 보장 표현 · 배송 가능 국가 · 서비스 가능 지역 · SNS URL · 전화번호 · 주소 · 로고 URL

**금지 표현 사전 검출 대상**
`1위` `최고` `최상` `보장` `100%` `완치` `부작용 없음` `업계 유일` `국내 최초` `공식 인증` (근거 미확인 시)

→ 초안에 포함되면 `STEST-005`가 산출을 차단한다.

## 3. 사이트 유형별 입력값 (원본 §4-3)

쇼핑몰이 아니면 상품 URL 목록을 요구하지 않는다. 유형에 맞게 대체한다.

| 유형 | 대체 입력값 |
|---|---|
| **쇼핑몰** | 상품 URL 목록 · 상품명 · 카테고리 · 상품 SEO 설정 여부 · 상세설명 텍스트 여부 · 상세설명 통이미지 여부 · 기존값 여부 · 전자상거래 추적 필요 여부 |
| **B2B** | 서비스 URL 목록 · 사례 URL 목록 · 문의 URL |
| **병원·의원** | 진료/시술 URL 목록 · 의료진 URL · 오시는 길 URL |
| **펜션·숙박** | 객실 URL 목록 · 예약 URL · 오시는 길 URL |
| **랜딩페이지** | 랜딩 URL · 신청 폼 URL · CTA 목적 |
| **일반** | 주요 메뉴 URL 목록 |

> **병원·의원은 특히 주의.** 치료 효과·보장 표현·전문 자격은 의료광고 규제 대상이다. 확인되지 않으면 넣지 않고, 확인되어도 표현을 강화하지 않는다.

## 4. SEO/GEO/AEO 작성 규칙

### 4-1. 메타 디스크립션
실제 페이지 내용 기준 · 키워드와 자연스럽게 연결 · 과장 금지 · 미확인 수치·후기·1위·최고·보장 금지 · 너무 길거나 짧으면 조정 후보로 표시

### 4-2. OG
OG title · OG description · OG image 확인. 카카오·네이버 공유 시 어색한지, 브랜드명 중복인지, 이미지 누락인지 점검.

### 4-3. H태그
H1은 페이지 핵심 주제 1개 권장 · H2는 주요 섹션 · H3는 세부 설명 · 디자인 목적으로 남발되면 문제로 표시.
**아임웹 구조상 직접 제어가 어려우면 `디자인모드 확인 필요`로만 표시하고, INV-11에 따라 수정하지 않는다.**

### 4-4. AEO
페이지 상단 2~3문장 요약문 · FAQ 후보 · 질문형 H2/H3 후보 · 짧고 명확한 답변 구조.
**실제 본문과 일치하는 FAQ만** JSON-LD 후보로 만든다.

### 4-5. GEO
적용 위치: 푸터 · 오시는 길 · 연락처 · 지도 · 서비스 가능 지역 · 배송 가능 국가 · 방문 가능 지역
**지역 기반 서비스가 아니면 지역명을 억지로 반복하지 않는다.** 미확인 서비스 범위는 넣지 않는다.

## 5. 다국어 SEO 규칙 (원본 §17)

글로벌 모드 사용 시 언어별로 분리한다.

**확인 항목**
언어별 URL 구조 · 언어별 SEO 입력칸 · 언어별 페이지 제목 · 언어별 페이지 설명 · 언어별 OG · 언어별 상품 SEO · 공통 Header Code 적용 범위 · 언어별 Header Code 가능 여부 · JSON-LD 공통/언어별 적용 여부 · sitemap 언어별 URL 포함 여부 · hreflang 자동 생성 여부 · canonical 언어별 처리 여부

**주의**
- Header Code · JSON-LD · robots.txt · llms.txt는 본문처럼 **자동 번역되지 않는다.** 그렇게 가정하지 않는다.
- 언어별 적용 위치가 확인되지 않으면 **공통 최소 버전만** 제안한다.
- 메타 키워드는 언어별로 다르다. 한국어 키워드를 기계 번역해 타 언어 메타에 넣지 않는다. `현지 키워드 확인 필요`로 표시한다.

## 6. 자료 충돌 처리 (원본 §5)

| 상황 | 표시 |
|---|---|
| 공개 페이지 ≠ 관리자 | 반영 불일치 |
| 관리자 ≠ 디자인모드 | 관리자-디자인모드 대조 필요 |
| 로컬 코드 원본 없음 | 원본 백업 필요 |
| 확인되지 않은 정보 | 반영하지 않음 |
