# ENG-030 마운트 전략 (REQ-013, §18.3)

| 순위 | type | 설명 | 아임웹 수정 |
|---|---|---|---|
| 1 | `none` | 전역 동작·플로팅 UI. DOM 앵커 불필요 | 불필요 |
| 2 | `slot` | 설치 시 심어둔 `data-ddak-slot` 요소에 렌더 | 불필요 |
| 3 | `selector` | 아임웹 기본 DOM 셀렉터를 앵커로 사용 | 불필요하나 업데이트에 취약 |
| 4 | `new-slot` | 프리셋에 없는 새 위치 필요 | **1회 수정 → 승인 대상. 여기서 멈춘다** |

- 에이전트는 1 → 2 → 3 순으로 판정한다. 4가 불가피하면 **작업을 멈추고 승인을 요청**한다 (AC-019).
- `registry.ts` 는 mount.type 이 new-slot 인 항목을 만나면 예외를 던진다 — 승인 없이 registry에 실리지 않는다.
- 로더는 앵커를 못 찾아도 **오류로 처리하지 않고 조용히 건너뛴다** (사이트 파손 방지, P-9).
- 슬롯 프리셋 위치·개수는 `OPEN-REG-02` (사용자 결정 대기).
