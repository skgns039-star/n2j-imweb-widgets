# ENG-044 연결 락 (§24.6)

구현: `state/threads.sqlite3` 의 `connect_locks` 테이블 (`src/bot/onboarding.ts`).

| 항목 | 규칙 |
|---|---|
| 단위 | `site_id` 1개당 락 1개 |
| 획득 | 위저드가 site_id를 확정하는 순간 |
| 충돌 | 다른 대화가 보유 중이고 만료 전이면 **두 번째는 거부** |
| 해제 | 위저드 만료·취소·완료 시. 한 대화가 가진 락은 모두 함께 해제된다 |
| 회수 | 만료 시각(15분) 경과 시 자동. 프로세스 재시작과 무관하게 동작한다 |
| 커밋 직전 | `holdsLock()` 재확인. **미보유면 커밋하지 않는다** (INV-9) |

락을 잃은 상태에서의 커밋은 "두 대화가 같은 사이트를 서로 다른 값으로 확정"하는 경로다. 그래서 경고가 아니라 중단이다.

검사: TEST-056 / PTEST-041.
