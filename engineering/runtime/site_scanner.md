# ENG-042 사이트 상태 스캐너 (REQ-031, REQ-034 / §24.3)

구현: `src/bot/scan.ts`. **읽기 전용이다.** 로그인하지 않고 공개 페이지만 연다.
스캔 단계에서 아임웹에 쓰기가 1건이라도 발생하면 설계 위반이다 (§24.13).

## 방식
- **Playwright 렌더링 후 DOM** 기준. 정적 HTML fetch 단독으로 판정하지 않는다.
- 브라우저를 띄우지 못하면 **정적 fetch로 대체하지 않고 실패**한다 (fail-closed).
- 표본: 홈 + 사용자 지정 경로, 최대 5페이지. **전수 아님.**
- 결과 첫 줄에 표본 한계 고지를 고정 출력한다.
- 저장: `state/site_scans/<site_id>_<ts>.json`. **secretscan 대상**이다(외부 스크립트 URL에 키가 섞일 수 있음).

## 수집 항목
| ID | 항목 |
|---|---|
| S1 | 로더 태그 수 + `window.__ddak.loader` (버전 판정은 **URL이 아니라 이 객체 기준**, §24.2) |
| S2 | 우리 것이 아닌 외부 스크립트 src 목록·인라인 개수 |
| S3 | `data-ddak-slot` 이름과 개수 |
| S4 | `window.__ddak` 존재 · `ddak-` 클래스 |
| S5 | 이미 로드된 공용 라이브러리(jQuery·Bootstrap)와 버전 |
| S6 | `registry.json` 참조와 응답 상태·스키마 유효성 |

## 판정 (C1~C4)
| 코드 | 상태 | 처리 |
|---|---|---|
| C1 | 로더 0개 | 신규 삽입 경로 |
| C2 | 1개·최신 | **심지 않는다.** "이미 연결됨" 후 manifest 정합화만 |
| C3 | 1개·구버전 | INV-2 예외 → **명시 승인** 필요 (diff·영향 위젯·되돌리기 포함) |
| C4 | 2개 이상 | **즉시 중단.** 유지/제거 대상만 제시하고 자동 제거하지 않는다 |

## 충돌 (E)
- **E1** slot 이름 중복(한 페이지 안에서) · **E2** 호스트 CSS의 `ddak-` 정의 · **E4** 라이브러리 중복 로드
  → 경고가 아니라 **연결 실패**다.
- **E3** z-index는 §24.10에 따라 **표본에서 관측된 최대값 보고만** 한다. 가려짐 판정은 사용자 육안 확인 항목이다.

## 정본 판정 (§24.5)
"어느 쪽이 정본이냐"를 **묻지 않는다.** 정본은 언제나 Git이다 (INV-3).

| 상황 | 판정 | 행동 |
|---|---|---|
| 사이트에 있고 Git에 없음 | 드리프트 | 기록만. 손대지 않음 |
| Git에 있고 사이트에 없음 | 미배포 | 재배포 여부를 묻는다 |
| 양쪽 버전 불일치 | 불일치 | **정본 기준 재배포** 제안. 사이트를 정본으로 승격하지 않음 |
