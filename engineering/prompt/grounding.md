# ENG-006 자료 기반 Grounding

- 결정: APPLY / 근거: 잘못된 플랫폼 가정 차단

## 확인된 사실 (아임웹 공식, 확인일 2026-08-24)
1. 코드 위젯은 클라이언트 사이드 언어만 지원하고, 저장 시 **주석이 제거된 상태로** 저장된다. → 왕복 편집은 바이트 동일성을 보장할 수 없다 (REQ-003 설계 근거).
2. 공통 CSS·JS는 `환경설정 > SEO > 공통 코드 삽입`에 넣고 코드 위젯에서 호출하는 방식이 권장된다. → 로더 + 외부 서브파일 구조는 플랫폼 권장 경로와 일치.
3. 직접 입력한 스크립트는 정기 업데이트로 적용되지 않거나 수정이 필요할 수 있다. → 회귀 감시 필요(STANDARD).
4. 개발자센터 Open API Reference에 `Script` 그룹이 존재한다.
5. REST API는 API Key·Secret이 필요하며 키는 **사이트 단위** 발급이다.
6. 공통 코드 삽입은 **유료 요금제** 기능이다.

## 자료 기반 추론 (사실 아님, 확인 필요로 표시)
- `Script` API가 타 플랫폼 ScriptTag 계열처럼 스크립트 등록·갱신을 지원할 **가능성**이 있다 → CHK-001.

## 규칙
- 위 1~6만 "확인된 사실"로 인용한다. 그 외는 `확인 필요`로 표시하고 추측을 사실로 말하지 않는다.
- 아임웹 코드 비교는 **주석 제거 정규화본**으로만 한다 (`src/release/hash.ts` normalizeCode).
