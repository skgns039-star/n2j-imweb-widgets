# ENG-009 Routing

- 결정: APPLY / 구현: `src/bot/router.ts` classify()
- 예방: "되돌려"를 배포로 처리하는 오라우팅

| 의도 | 트리거(한국어) | 경로 | 승인 |
|---|---|---|---|
| approve | 승인 / approve (+ AP-id) | 저장된 승인 실행 | - |
| reject | 거절 / 취소 | 승인 폐기 | - |
| kill | 전체 중지 / 킬 스위치 | global_enabled=false + purge | **없음** (사고 대응, §22.1) |
| resume | 전체 재개 | 승인 요청 후 실행 | 필요 |
| rollback | 되돌려 / 롤백 / 이전 버전 | 승인 요청 → rollback.ts | 필요 |
| deploy | 배포 / 반영해 | 승인 요청 → deploy.ts | 필요 |
| install | 설치 / 로더 / 스니펫 | `loader/LOADER_SNIPPET.md` 회신 | 아임웹 쓰기는 승인 |
| inspect | 상태 / 조회 / 해시 | manifest + 로컬 무결성 요약 | - |
| agent | 바꿔 / 수정 / 추가 / 만들어 | SDK 엔진 위임 | 배포 단계에서 |
| unclear | 그 외 | **한 번만** 되묻는다 | - |

**원칙:** 승인·무결성·킬스위치는 LLM을 거치지 않고 결정적으로 판정한다. 모델이 승인을 창작할 여지를 만들지 않는다.

## ENG-045 인텐트 경계 (§24.8)

"연결"은 다른 문맥에도 등장한다 — 예: "이 위젯을 저 슬롯에 연결해줘".

| 규칙 | 내용 |
|---|---|
| 토큰·문맥 판정 | 한국어 조사·어미 때문에 `\b` 가 오작동한 선례가 있다. 단어 경계 대신 **토큰 포함 여부**로 본다 |
| 엔티티 동반 시 제외 | 문장에 위젯·슬롯·registry·모듈·등록된 widget_id 가 함께 나오면 **connect로 라우팅하지 않는다** |
| 애매하면 되묻는다 | 임의 분기 금지. 한 번만 확인 질문을 낸다 |
| 사고 대응 우선 | "전체 중지"·킬 스위치는 위저드 진행 중에도 즉시 처리된다 |
| 위저드 우선 | 위저드가 진행 중이면 그 밖의 입력은 전부 현재 단계의 답으로 해석한다 (탈출구: 취소 / 이어서 / 연결) |

추가 인텐트: `connect`(연결·연동·붙여줘·setup) / `migrate`(이관) / `remove_original`(원본 제거).

검사: TEST-058 / PTEST-042.
